# بصيرة الأرض — سورس التشغيل المحلي المجاني

هذا التسليم يعتمد على ملف Governorate Atlas الأخير، مع التعديل المتفق عليه: تشغيل محلي دون خادم أو خدمات مدفوعة، واستبدال الرسائل والمكالمات بتنبيهات داخل التطبيق أثناء فتحه.

**ليس تنفيذًا كاملًا لكل وعود الدراسة.** راجع REQUIREMENTS_STATUS.md: أطلس الملوحة، بيانات قواعد المحاصيل المعتمدة، التصنيف الآلي للمحاصيل، وقراءة المنتجات الرقمية لكل مهمات ناسا ليست مكتملة. لم نضع قياسات وهمية مكانها.

## التشغيل على Windows

1. ثبّت Python 3.12 أو أحدث إصدار متوافق مع المكتبات؛ بيئة الاختبار Python 3.12.
2. فك الملف المضغوط في مجلد عادي (مثل Documents/AgriSight).
3. انقر مرتين على `start-windows.bat`. أول تشغيل ينزّل المكتبات، ويحتاج إنترنت.
4. افتح `http://127.0.0.1:8765` في المتصفح بعد ظهور رسالة تشغيل الخادم.
5. اترك نافذة التشغيل مفتوحة. لإيقاف التطبيق اضغط Ctrl+C فيها.

بعد أول تثبيت، يمكنك تشغيل `.venv\Scripts\python.exe run.py` مباشرة دون إعادة تنزيل المكتبات. لا تفتح index.html مباشرة؛ الواجهة تحتاج الخادم المحلي.

على Linux/macOS: شغّل `sh start.sh` في المجلد. بعد التثبيت: `.venv/bin/python run.py`.

## المكونات

- `web/`: واجهة عربية بثلاث شاشات، HTML/CSS/JavaScript.
- `backend/app.py`: واجهات الخادم المحلي وSQLite وحماية الطلبات من المواقع الأخرى.
- `backend/core.py`: تقسيم مساحة الحقل، حساب المياه، مقارنة التجارب والحزم الموسمية.
- `backend/providers.py`: الطقس وNASA POWER وSoilGrids WCS وفهرسة Earthdata.
- `backend/satellite.py`: قراءة باندات Landsat مع QA، ومتوسط NDVI لبكسلات الحقل، وقصة GIF محاذاة مكانيًا.
- `data/governorates.geojson`: حدود المحافظات الـ٢٧، مع ملف مصدر وترخيصها.
- `tests/`: اختبارات وظيفية وحسابية. `python -m pytest -q`.

## ما يعمل دون إنترنت بعد التثبيت

فتح الخريطة الإدارية، حفظ/قراءة الأراضي والخطط والتجارب والصور، العمليات الحسابية، وسجلات مشاركة المعدات، والبيانات التي جرى تحميلها سابقًا. لا يمكن جلب طقس جديد أو صور قمر جديدة دون إنترنت. التعرف على الكلام يعتمد على المتصفح وقد يستخدم خدمة إنترنت؛ لا يوجد ضمان لتوافر صوت عربي محلي على كل جهاز.

البيانات الجديدة تُجلب عند الضغط على زر تحديث فقط. هذا يرسل إحداثيات الحقل للمصدر المختار. لا توجد اتصالات SMS أو مكالمات أو اشتراكات.

## حدود الاستخدام

- التطبيق مخصص لمشغّل واحد على localhost؛ يستطيع مرشد واحد إدارة عدة أراضٍ. لا توجد حسابات منفصلة أو مزامنة أجهزة. لا تغيّر عنوان الاستماع إلى 0.0.0.0 ولا تعرضه للإنترنت دون إضافة مصادقة وحماية ملائمة.
- السجلات تُنشأ في `data/agrisight.sqlite3` والصور في `data/photos/`. زر النسخ الاحتياطي يصدّر السجلات JSON ولا يصدّر ملفات الصور. للنسخة الكاملة: أغلق الخادم وانسخ مجلد `data` كله.
- حزمة الموسم JSON أصغر من 2,000,000 بايت، وتحتوي بيانات الأرض والأطلس الإداري والطقس المحفوظ والخطة فقط. لا تشمل مكتبات التطبيق ولا الصور ولا الصوت ولا الفيديو، وليست حجم البرنامج الكامل.
- لا يمكن تعميم نوع تربة واحد على المحافظة. SoilGrids تقديرات نموذجية بدقة 250 م لعمق 0–5 سم، وليست تحليل ملوحة أو قياسًا معمليًا.
- حاسبة المياه لا تشمل مخزون التربة أو غسيل الأملاح؛ لا تستخدمها كأمر تشغيل آلي للري.
- الرسم الإحداثي للحقل ليس خريطة قمر صناعي أو رفعًا مساحيًا. اضغط النقاط بالترتيب؛ التقسيم 20% تقريب هندسي.
- صور المساهمات ليست معايرة علمية للأقمار، ونقاط المشاركة داخلية وغير مالية.
- تنوع محاصيل الجيران يُعرض من السجلات المحلية وبحد أدنى للتجميع، وليس من تصنيف الأقمار.
- لا يتضمن السورس مفاتيح حسابات أو تسجيل دخول خارجي أو بيانات مستخدمين مسبقة.

## قواعد المحاصيل

لا نضمّن قواعد زراعية غير مراجعة. يمكن إضافة `data/crop_rules.json` كمصفوفة سجلات، كل سجل يحتوي: name، family، soils، seasons، max_ec_ds_m، source_url، reviewed_by. تطابق النصوص العربية للتربة والموسم مع خيارات الواجهة مطلوب. ملوحة الحقل تُدخل من نتيجة معملية. المحرك قواعدي وليس نموذجًا مدربًا؛ لا يُنفَّذ قرار زراعي تلقائيًا.

نجح 17 اختبارًا آليًا في بيئة التسليم، إضافة إلى فحص صياغة JavaScript وPython. هذه اختبارات برمجية لا تحقق ميداني. راجع LIVE_CHECKS.json لاتصالات المصادر التي تم اختبارها. لم تُختبر بيئة Windows أو الميكروفون على جهازك، ولا جميع المهمات الفضائية.
